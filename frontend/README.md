# SmartOrder Frontend

Next.js App Router UI matching the **Smart Order Allocation System UI_UX** Figma Make design.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Run

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
