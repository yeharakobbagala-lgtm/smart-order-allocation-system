1. How admin-only access works

You already have this in security.py:

def require_admin(
    current_user: dict = Depends(get_current_user),
) -> dict:
    if current_user["role"] != "admin":
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Admin access required.",
        )

    return current_user

Think of it like a security guard:

Request
   ↓
JWT token
   ↓
get_current_user()
   ↓
Who is this?
   ↓
require_admin()
   ↓
role == "admin" ?
   ├── YES → Allow
   └── NO  → 403 Forbidden

So we don't check the role manually inside every service.

For example:

Python represents durations using:

timedelta

##🧮 MATHEMATICS — Step 1: Distance

We need the geographical distance between two coordinates.

We'll use the Haversine formula.

You don't need to memorize the formula, but you should understand what it does:

It calculates the approximate straight-line distance between two points on Earth using their latitude and longitude.

The formula is:

$$ a = \sin^2(\frac{\Delta\phi}{2}) + \cos(\phi_1)\cos(\phi_2) \sin^2(\frac{\Delta\lambda}{2}) $$ $$ c = 2\arctan2(\sqrt a,\sqrt{1-a}) $$ $$ Distance = R \times c $$

where:

\(φ\) = latitude in radians
\(λ\) = longitude in radians
\(R\) = Earth's radius ≈ 6371 km

🧮 Let's understand the calculation

Suppose:

The function converts the coordinates to radians:

degrees → radians

Then applies the Haversine formula.
